# Note Patterns

## MOC Note

Use for topic entry points.

```markdown
# Topic MOC

## 一句话

用 1-2 句话说明这个主题是什么、为什么值得放进知识库。

## 学习路径

1. [[02 First Concept]]
2. [[03 Second Concept]]

## 核心笔记

- [[02 First Concept]]: 简短说明。
- [[03 Second Concept]]: 简短说明。

## 相关主题

- [[Related Topic]]

## 来源

- Source path or URL, date, or conversation context.
```

## Concept Note

Use for reusable ideas.

```markdown
# Concept Name

## 核心概念

解释概念，不要只复制原文。

## 为什么重要

说明用途、价值、边界。

## 怎么使用

给步骤、例子或判断标准。

## 相关

- [[Topic MOC]]
```

## Tutorial Note

Use for how-to material.

```markdown
# Tutorial Name

## 适用场景

## 前置条件

## 步骤

1. ...
2. ...

## 常见问题

## 相关
```

## Project Knowledge Note

Use when content belongs to a concrete project.

```markdown
# Project Knowledge

## 当前目标

## 已知材料

## 决策记录

## 下一步

## 相关文件
```

## Skill Inventory Note

Use when organizing Codex skills, tools, or plugins.

```markdown
# Skill Inventory

## 总览

## 已安装 Skill

| Skill | 用途 | 触发场景 | 备注 |
| --- | --- | --- | --- |

## 推荐组合

## 待补 Skill
```
