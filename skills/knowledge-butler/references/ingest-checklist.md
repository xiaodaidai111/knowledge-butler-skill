# Ingest Checklist

Run this checklist before final handoff.

## Structure

- There is one clear entry note or MOC.
- Every child note is linked from the MOC or another parent note.
- Folder placement matches the vault's existing style or the fallback taxonomy.
- Note filenames are Windows-safe.

## Knowledge Quality

- The text is reorganized, not dumped blindly.
- Each note has a durable purpose.
- Important definitions, workflows, and decisions are preserved.
- Source context is recorded when available.

## Obsidian Fit

- `[[wikilinks]]` point to intended note titles.
- Related notes are linked where useful.
- Markdown headings are consistent.
- No secrets, tokens, `.env` values, or private credentials are copied.

## Handoff

- Final response lists created and updated files.
- Final response identifies the MOC note.
- Any skipped or ambiguous material is called out.
