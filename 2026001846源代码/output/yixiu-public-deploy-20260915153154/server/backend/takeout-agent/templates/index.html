01 / 洞察引擎

洞察引擎

多维度融合：卫生巡检 + 评价信号 + 配送链路 + 包装材质。输出清晰、可展示的卫生评分与风险标签。

Knowledge

专业知识库

覆盖高温塑料、冷链、生熟分离、卫生巡检指标与消费者自检清单。

Explain

可解释评分

评分公式融合巡检、差评占比、投诉密度与包装风险，可追溯每个权重。

Vision

图像识别

识别塑料容器与油脂特征，提示高温风险与膳食负担。
